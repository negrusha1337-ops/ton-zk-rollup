# ZK-rollup на TON — исследовательский прототип

Цель проекта — rollup с EVM на TON: блоки исполняются вне цепочки, доказываются zkVM, а
контракт на TON проверяет доказательство и хранит слово состояния.

**Что здесь есть сейчас (15.11.2026).** Не продукт, а работающий прототип:

- проверка Groth16 на BN254 прямо в TVM (программное спаривание) — так контракт принимает
  пруфы SP1 и RISC Zero без перевода на другую кривую;
- rollup-контракт протокола версии 2: батчи с проверкой пруфа, депозиты и выводы TON, очередь
  L1 с принудительными транзакциями, публикация данных батчей в TON, заморозка и аварийный выход
  счёта EVM без пруфа;
- программа для zkVM SP1 (`zkvm-evm/`): блок EVM исполняется Reth внутри SP1; депозиты —
  зачисления в блоках, выводы — через мост, предустановленный в генезисе.

**Чему здесь нельзя верить.** Код не проходил аудит людьми. Независимые проверки
агентами-рецензентами уже находили в нём критичные дыры — в том числе в версиях, прошедших
testnet. Что найдено, что исправлено и что осталось открытым — [REVIEW.md](REVIEW.md).
Только Sandbox и testnet; настоящих денег здесь быть не должно.

**Протокол версии 2 (15.11.2026)** — [PROTOCOL-V2.md](PROTOCOL-V2.md). Одиннадцать слов
публичных значений; принудительной может быть только транзакция вывода через мост (до
256 байт), негодную программа пропускает — мусор в очереди rollup не останавливает; батч сам
заявляет, докуда обработал очередь (не больше 32 элементов за раз); дерево выводов с дозаписью;
время блока привязано ко времени L1; выход по пруфу zkVM удалён — после заморозки баланс
обычного счёта выходит по доказательству Merkle-Patricia и подписи Ethereum прямо в TVM.

Три блока цепочки настоящего узла Reth доказаны пруфами Groth16 на ноутбуке (20–25 минут на
пруф) и приняты настоящим контрактом **в Sandbox**: батчи 950 178 / 949 452 / 951 962 gas из
лимита 1 млн, вывод через мост 22 944, аварийные выходы двух счетов 73 646 и 99 623, «лучшая
подделка» отклонена кодом 7300 за 946 878 (`tests/RollupEvmRethProof.spec.ts`,
`bench/rollup-evm-reth-proof.json`). Блок 3 несёт десять принудительных транзакций с негодными
подписями. Четыре круга независимой проверки (13–16), последние два — без критичных находок.

**В testnet версия 2 прошла 15.11.2026** на контракте `EQA9ohM26MxwBxY2Hhr-0QBqIqWfSYYrEbvgbFsNFjznASNW`: 76 транзакций, неуспешных нет; газ батчей (950 178 / 949 452 / 951 962) и аварийных выходов (73 646 / 99 623) совпал с Sandbox до единицы; пять выводов через мост и оба выхода выплачены ровно по разу (`bench/testnet-run-reth.json`) — [TESTNET.md](TESTNET.md).

**Чего у версии 2 нет.** Выбранного срока
заморозки (минимум контракта в час — технический: при прувере-ноутбуке заморозку можно купить
спамом очереди примерно за 2 TON, [REVIEW.md](REVIEW.md), 14-4 и 15-8); выхода для монет на
контрактах L2 и токенов; сборщика блоков и прувера как сервисов; jetton'ов и управления.
Известные ограничения — [ARCHITECTURE.md](ARCHITECTURE.md), план — [ROADMAP.md](ROADMAP.md).

## Быстрый старт

```bash
npm ci
npx jest --maxWorkers=2
cd zkvm-evm && cargo test --release --locked -p rollup-evm
```

Circom и SP1 для тестов не нужны: ключи и доказательства лежат в `fixtures/`.

## Пересборка ZK-артефактов игрушечных схем

Нужны Rust (для сборки Circom) и Node.js 22+.

```bash
cargo install --git https://github.com/iden3/circom.git --tag v2.2.3 --root .tools circom
npm run zk:build
npm run zk:verifiers
npx blueprint test
```

Trusted setup здесь одноучастниковый и годится только для тестов. Программа zkVM и пруфы
SP1 — в [PROVING.md](PROVING.md).
